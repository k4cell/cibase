Régua de Relacionamento (Farol de Risco)

Em quantos dias sem comprar um cliente muda de cor no painel. Cada negócio tem um ciclo diferente — uma clínica de estética pode usar ~30 dias, um centro automotivo pode usar ~180.

Com esses números: até {{ configuracoesService.diasAtencao }} dias sem comprar, o cliente aparece Saudável (verde); de {{ configuracoesService.diasAtencao + 1 }} a {{ configuracoesService.diasRisco }} dias, Atenção (amarelo); acima de {{ configuracoesService.diasRisco }} dias, Risco Alto (vermelho).
